دليل استخدام قالب نوافذ

نوافذ قالب صفحات هبوط احترافي مكتوب بـ HTML5 و CSS3 و JavaScript خالصة، يأتي بنظام تصميم واحد و5 نماذج جاهزة (منصة SaaS، تطبيق جوال، وكالة رقمية، عيادة طبية، أكاديمية ودورات)، وكل نموذج بنسختين: عربية من اليمين لليسار وإنجليزية من اليسار لليمين.

لا يحتاج القالب إلى أي أدوات بناء أو مكتبات أو اتصال بالإنترنت: افتح أي ملف HTML في المتصفح مباشرة.

البدء السريع

  1. فك ضغط الملف، وافتح index.html لاستعراض كل النماذج.
  2. اختر النموذج الأقرب لنشاطك، مثل clinic.html ونسخته الإنجليزية clinic-en.html.
  3. عدّل النصوص مباشرة في ملف HTML، والألوان من assets/css/theme.css.
  4. اربط نموذج التواصل (انظر قسم النماذج)، ثم ارفع المجلد إلى استضافتك.

لتجربة القالب عبر خادم محلي (اختياري):

cd nawafidh
python -m http.server 8080
# ثم افتح http://localhost:8080

الألوان والخط

كل الألوان متغيرات CSS في assets/css/theme.css. القيم في :root تخص نموذج SaaS، وكل نموذج آخر له كتلة [data-demo="..."]، وللوضع الليلي كتل [data-theme="dark"].

[data-demo="clinic"] {
  --brand: #0369a1;         /* اللون الأساسي للأزرار والروابط */
  --brand-strong: #075985;  /* عند المرور بالمؤشر */
  --brand-soft: #e0f2fe;    /* خلفيات الأيقونات والشارات */
  --gradient: linear-gradient(135deg, #0369a1, #0891b2);
}

يستخدم كل نموذج السمة data-demo على وسم <html>. لتغيير الخط عدّل --font واستبدل ملفات assets/fonts (خط Cairo مضمّن محليًا ويدعم العربية واللاتينية).

العربية والإنجليزية (RTL / LTR)

لكل صفحة ملفان: العربي name.html بـ dir="rtl"، والإنجليزي name-en.html بـ dir="ltr". زر اللغة في الترويسة ينقل الزائر للنسخة الأخرى ويحافظ على القسم الحالي. التنسيقات تستخدم الخصائص المنطقية (inline-start) فتعمل في الاتجاهين دون ملف CSS منفصل، ووسوم hreflang تربط النسختين لمحركات البحث.

إذا أردت لغة واحدة فقط: احذف الملفات التي لا تحتاجها، واحذف زر اللغة من الترويسة.

الوضع الليلي

يتبع القالب إعداد جهاز الزائر تلقائيًا، ويحفظ اختياره عند الضغط على زر القمر/الشمس. يُطبَّق الوضع قبل رسم الصفحة (سكربت قصير في <head>) فلا يظهر وميض. لتعطيله احذف الزر والسكربت.

مكتبة الأقسام

صفحة sections.html تعرض أكثر من 20 قسمًا بكل أشكالها: 5 أشكال للبطل، شبكة وصفوف للمزايا، 3 أشكال للأسعار، بورتفوليو، فريق، مدونة، منهج، ساعات عمل، عد تنازلي، نشرة، دعوة، وتواصل. لتركيب صفحة جديدة انسخ أي كتلة <section> والصقها في صفحتك، وكل الأقسام تأخذ ألوان النموذج تلقائيًا.

النماذج والربط

أي نموذج يحمل السمة data-validate يتحقق من الحقول في المتصفح (مطلوب، بريد، جوال، طول أدنى، تاريخ، موافقة) مع رسائل خطأ بلغة الصفحة وحقل مخفي ضد الرسائل المزعجة.

  • بدون ربط (الافتراضي): ينتقل الزائر إلى thank-you.html عبر data-redirect، أو تظهر رسالة نجاح.
  • Formspree أو أي خادم: أضف عنوان الاستقبال، فيُرسل النموذج بطريقة POST:
<form data-validate data-endpoint="https://formspree.io/f/XXXXXXX" data-redirect="thank-you.html">
  • Netlify Forms: أضف name="contact" data-netlify="true" واحذف data-endpoint.
  • واتساب: زر «إرسال عبر واتساب» يجمع الحقول في رسالة ويفتح واتساب. غيّر الرقم في data-whatsapp="9665XXXXXXXX" (بصيغة دولية بدون +).
  • PHP: استخدم data-endpoint="send.php" واقرأ الحقول من $_POST في ملفك.

الأسعار والعداد والسلايدر

  • الأسعار: كل سعر يحمل data-monthly وdata-yearly، وزر data-billing يبدّل بينهما.
  • العد التنازلي: غيّر التاريخ في data-countdown="2026-12-31T20:00:00".
  • العدادات: الرقم في data-count="12000" يتحرك عند ظهوره (يحترم إعداد تقليل الحركة).
  • السلايدر: يعمل بالسحب على الجوال وبالأزرار والنقاط، بدون مكتبات.
  • الأسئلة الشائعة والمنهج: عناصر <details> أصلية تعمل حتى بدون JavaScript.

تحسين محركات البحث

كل صفحة تحتوي على عنوان ووصف ورابط canonical ووسوم Open Graph و Twitter و hreflang وبيانات منظمة JSON-LD. قبل النشر استبدل https://example.com/ بنطاقك في الصفحات وفي sitemap.xml وrobots.txt، وضع صورة المشاركة في assets/img/og-image.png (1200×630).

الأداء: خط محلي بصيغة woff2 مع font-display: swap وتحميل مسبق، رسومات SVG مضمّنة بدل الصور، JavaScript واحد مؤجل (defer)، ولا توجد أي طلبات لخوادم خارجية.

النشر

  • استضافة عادية (cPanel): ارفع محتوى المجلد إلى public_html، وأعد تسمية الصفحة التي تريدها رئيسية إلى index.html.
  • Netlify / Vercel / GitHub Pages: اسحب المجلد أو اربطه بمستودع، فلا توجد خطوة بناء.

المصادر والتراخيص

  • خط Cairo — SIL Open Font License 1.1 (ملف assets/fonts/OFL.txt)، المصدر: github.com/Gue3bara/Cairo عبر حزمة fontsource.
  • الأيقونات والرسومات التوضيحية SVG من تصميم مؤلف القالب، ولا توجد صور بحقوق نشر أو صور لأشخاص.
  • لا يعتمد القالب على أي مكتبة أو إضافة مدفوعة.
