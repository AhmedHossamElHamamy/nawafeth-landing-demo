# أثر | Athar: قالب موقع وكالة تصميم وتسويق (الإصدار 1.0.0)

تصميم واحد متكامل لموقع كامل متعدد الصفحات، بنسخة عربية RTL ونسخة إنجليزية LTR ووضع ليلي.

## الصفحات (13 صفحة × لغتان = 26 ملف HTML)
الرئيسية، الخدمات + الباقات، معرض الأعمال بفلترة، دراسة حالة، من نحن، الوظائف، المدونة بفلترة التصنيفات، صفحة مقال، تواصل + خريطة + ساعات العمل، سياسة الخصوصية، الشروط والأحكام، صفحة 404، صفحة الشكر.

## البدء
افتح `index.html` في المتصفح. الدليل الكامل في `docs/index.html`.

## التخصيص
- الألوان والخط: `assets/css/theme.css`
- المكونات: `assets/css/style.css` و `assets/css/pages.css`
- التفاعلات: `assets/js/main.js` و `assets/js/pages.js`

## ملاحظات
كل الأسماء والآراء والأرقام محتوى تجريبي. خط Cairo مرخص بـ SIL OFL 1.1.
